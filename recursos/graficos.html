Ingeniería inversa de MADMIX1.BIN — ver src/FINDINGS.md para el detalle técnico completo.

Este documento se va enriqueciendo a medida que identificamos más gráficos. Los datos de cada loseta están embebidos como hex en el <script> al final del fichero, junto con el objeto TILE_LABELS donde se van anotando las identificaciones confirmadas — para añadir una, solo hace falta rellenar esa entrada (índice → nombre).

Losetas del laberinto (data/tiles/*.til, 0xB940-0xC4A0, 91 gráficos)

Cada gráfico son 32 bytes (16×16 px, monocromo, 2 bytes/fila). El "tipo" viene de la tabla de colisión TILE_TYPES (0x8EC4, ver FINDINGS.md) indexada por el mismo número que el gráfico — pero ojo: se ha confirmado que "tipo" NO distingue muro de suelo (las 45 losetas de muro y las de suelo comparten tipo 0). El color de cada tarjeta de abajo refleja la identificación real (muro/suelo/especial), NO el valor de tipo — ese solo se muestra como dato de referencia.

muro (confirmado) suelo (confirmado) identificado, especial (flechas, pistas, puertas, decoración...) sin identificar todavía

Marco de caramelo (data/img/marco_caramelo_*.img, 256×192, RESUELTO)

No es una loseta ni un sprite — es una imagen completa de pantalla (la tabla de patrones VRAM entera, 6144 bytes) que se dibuja con tabla de nombres identidad (nombre = índice de patrón). La forma viene de una tabla RLE de 1740 bytes (TABLA_RLE_MARCO_CARAMELO, pares valor/repetición que se expanden a los 6144 bytes reales) y el color de un bloque de 768 bytes (LEVELCYCLE_RESOURCE_TABLE, madmix_scr.asm) que pasa por OBTENER_COLOR_VDP (antes TAIL_TILE_LOOKUP; dos consultas a TABLA_COLORES_VDP combinadas en un nibble alto/bajo) antes de llegar a VRAM. El centro sale en blanco a propósito: el laberinto se dibuja encima después. Verificado byte a byte contra un volcado real de VRAM — 0 diferencias en las 224 posiciones de color y en todos los bytes de forma donde el marco dibuja algo (las diferencias restantes son del laberinto/HUD de esa partida real, dibujados encima en el momento del volcado).

Área de composición (4×4)

Arrastra copias de las losetas de arriba a este cuadrado de 16 celdas contiguas — sirve para probar visualmente cómo encajan piezas de muro, comprobar conexiones, o montar un rincón de nivel de ejemplo. Una vez colocada, puedes arrastrar una loseta de una celda a otra para reubicarla (mueve, no duplica), rotarla 90° con el botón ⟳, o vaciarla con × (ambos botones aparecen al pasar el ratón por la celda). Se guarda solo en este navegador (localStorage), no se escribe en el fichero.

Arrastra desde la galería de arriba, o de una celda a otra para reubicar. ⟳ rota 90°, × vacía la celda.
